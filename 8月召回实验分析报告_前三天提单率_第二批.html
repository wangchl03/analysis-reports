02

分批次方向不一致，警惕样本波动。

三批次中两批对照组更高/持平，仅一批实验组领先。样本量（668）小于上一批（885），且批次间差异大，+1.11pp 的合并增量很可能被少数批次或噪声驱动。

03

与上一批（+6.52pp）对比：券效果随时间/批次衰减。

同样是无券 vs 3天券、同样的统计口径，上一批整体 +6.52pp、本批仅 +1.11pp。需要拉齐更多批次或检验是否与召回日、用户构成、市场环境相关，再判断是「衰减」还是「噪声」。

五、核心结论汇总

A

本批券的整体拉动微弱（+1.11pp）。

实验组 15.52% vs 对照组 14.41%，远低于上一批的 +6.52pp。

B

分批次方向不稳定（前两批反/持平，仅第三批正）。

0821_0826 -3.06pp、0822_0827 -0.13pp、0823_0828 +8.51pp，不足以得出稳定结论。

C

券仅对活跃用户有增量（+2.96pp），对沉默用户无效（-0.78pp）。

与上一批一致的方向：券的价值集中在高意向人群，但幅度明显变小。

六、策略建议

A

本批数据不支持「扩大投放」，建议先做稳健性验证。

券增量仅 +1.11pp 且分批次方向不稳定，应合并更多批次、或检验召回日/用户构成的影响后再决定投放策略。

B

券仍只对「第一阶段活跃用户」有效，继续聚焦高意向人群。

活跃用户 +2.96pp、沉默用户 -0.78pp，延续上一批的结论：券不要投给沉默用户。

C

第 1 天无拉动，可重排触达节奏或验证券配置。

上一批第 1 天 +2.92pp，本批第 1 天 -0.94pp，建议排查本批券是否准时下发、触达是否到位。

模块一：构建 3 批召回用户 + 前三天提单率
WITH u AS (
    SELECT churn_user_id::bigint AS user_id, ab_group, active_days_cnt, '2026-08-26'::date AS recall_date
    FROM wangchuanliang.no_apply_0821_0826_30pct
    UNION ALL
    SELECT churn_user_id::bigint, ab_group, active_days_cnt, '2026-08-27'::date
    FROM wangchuanliang.no_apply_0822_0827_30pct
    UNION ALL
    SELECT churn_user_id::bigint, ab_group, active_days_cnt, '2026-08-28'::date
    FROM wangchuanliang.no_apply_0823_0828_30pct
),
applied AS (
    SELECT DISTINCT o.user_id, o.apply_date FROM wangchuanliang.order_loan_f_v2_copy o
)
SELECT
    u.ab_group,
    COUNT(DISTINCT u.user_id)                                              AS 用户数,
    COUNT(DISTINCT CASE WHEN u.active_days_cnt > 0 THEN u.user_id END)     AS 第一阶段活跃用户,
    COUNT(DISTINCT CASE WHEN a.user_id IS NOT NULL AND a.apply_date BETWEEN u.recall_date AND u.recall_date + 2
                         THEN u.user_id END)                               AS 前三天提单用户,
    COUNT(DISTINCT CASE WHEN u.active_days_cnt > 0 AND a.user_id IS NOT NULL
                          AND a.apply_date BETWEEN u.recall_date AND u.recall_date + 2
                         THEN u.user_id END)                               AS 活跃且前三天提单
FROM u
LEFT JOIN applied a ON a.user_id = u.user_id
GROUP BY u.ab_group
ORDER BY u.ab_group;
模块二：前三天逐日提单
WITH u AS (
    SELECT churn_user_id::bigint AS user_id, ab_group, '2026-08-26'::date AS recall_date
    FROM wangchuanliang.no_apply_0821_0826_30pct
    UNION ALL
    SELECT churn_user_id::bigint, ab_group, '2026-08-27'::date FROM wangchuanliang.no_apply_0822_0827_30pct
    UNION ALL
    SELECT churn_user_id::bigint, ab_group, '2026-08-28'::date FROM wangchuanliang.no_apply_0823_0828_30pct
)
SELECT
    u.ab_group,
    COUNT(DISTINCT CASE WHEN o.apply_date = u.recall_date THEN u.user_id END)       AS 第1天提单,
    COUNT(DISTINCT CASE WHEN o.apply_date = u.recall_date + 1 THEN u.user_id END)   AS 第2天提单,
    COUNT(DISTINCT CASE WHEN o.apply_date = u.recall_date + 2 THEN u.user_id END)   AS 第3天提单
FROM u
LEFT JOIN wangchuanliang.order_loan_f_v2_copy o
       ON o.user_id = u.user_id AND o.apply_date BETWEEN u.recall_date AND u.recall_date + 2
GROUP BY u.ab_group
ORDER BY u.ab_group;
模块三：第一阶段活跃 / 沉默 × 前三天提单
WITH u AS (
    SELECT churn_user_id::bigint AS user_id, ab_group, active_days_cnt, '2026-08-26'::date AS recall_date
    FROM wangchuanliang.no_apply_0821_0826_30pct
    UNION ALL
    SELECT churn_user_id::bigint, ab_group, active_days_cnt, '2026-08-27'::date FROM wangchuanliang.no_apply_0822_0827_30pct
    UNION ALL
    SELECT churn_user_id::bigint, ab_group, active_days_cnt, '2026-08-28'::date FROM wangchuanliang.no_apply_0823_0828_30pct
),
applied AS (
    SELECT DISTINCT o.user_id FROM wangchuanliang.order_loan_f_v2_copy o
)
SELECT
    u.ab_group,
    CASE WHEN u.active_days_cnt > 0 THEN '活跃' ELSE '沉默' END            AS 分段,
    COUNT(*)                                                               AS 用户数,
    SUM(CASE WHEN a.user_id IS NOT NULL AND EXISTS (
                SELECT 1 FROM wangchuanliang.order_loan_f_v2_copy o2
                WHERE o2.user_id = u.user_id
                  AND o2.apply_date BETWEEN u.recall_date AND u.recall_date + 2
             ) THEN 1 ELSE 0 END)                                          AS 前三天提单
FROM u
LEFT JOIN applied a ON a.user_id = u.user_id
GROUP BY u.ab_group, CASE WHEN u.active_days_cnt > 0 THEN '活跃' ELSE '沉默' END
ORDER BY u.ab_group, 分段;
口径说明：3 批 T4 用户合并（召回日 08-26 / 08-27 / 08-28）。前三天 = 触达日 + 触达日+1 + 触达日+2（与 3 天券有效期一致）；第一阶段 = 上笔结清日至触达日前一天（4 天空窗期，如 0821_0826 批次为 08-22~08-25）；第一阶段活跃 = 空窗期内有活跃行为（active_days_cnt > 0）。提单以 order_loan_f_v2_copy.apply_date 判定。
⚠️ 本批券效果较上一批明显减弱（+1.11pp vs +6.52pp），且分批次方向不一致，样本量偏小（668），结论需谨慎。
