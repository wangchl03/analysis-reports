01

券的作用是「时间加速」，不是「行为区分」。

券把优质用户提前集中到第一周（实验组第一周回归者历史逾期 0.23，低于基线 0.28），而不是改变用户的犹豫行为。

02

剩余池浓缩效应。

优质用户被提前抽走后，实验组剩余池中高息（高风险定价）用户占比被动上升——第二周回归者高息率 0.351 vs 基线 0.304。

03

对照组无加速器，优质用户自然释放。

对照组第二周回归者高息率 0.220（全场最低），仍是好用户，因此其质量恶化被推迟。

04

完整机制闭环。

实验组质量曲线「好→差→差」与对照组「好→好→差」形状相同，只是实验组整体前移一个窗口——与到期口径的盈利率观察吻合（第二周对照组 19.59% vs 实验组 7.48%）。

四、核心结论汇总

01

券的拉动只存在第一周（券有效期内）。

第一周提单率实验组 32.73% vs 对照组 25.27%（+7.46pp）；第二周 +1.30pp、第三周 +1.45pp、21 天后 +2.47pp。券过期后两组待遇一致，转化差异大幅收窄。

02

第二周是质量分水岭（到期口径）。

第二周对照组盈利率 +19.59%，实验组降至 +7.48%，实验组逾期率反超（金额 28.70% vs 21.59%、订单 35.59% vs 27.03%）。

03

券的长期副作用：优质用户被前置消化。

券把「会回来」的优质用户集中在第一周转化（第一周实验组逾期率反而更低：16.43% vs 20.66%），导致实验组后续窗口的回归用户质量系统性变差——第二周起实验组的逾期率全面差于对照组。

04

到期口径下，降息已实现正盈利贡献。

实验组整体盈利率 17.97% 反超对照组 17.63%（+0.34pp），且三个逾期率全面更低——降息换还款率超过让利成本，券不仅不亏，反而通过压降坏账实现净收益；其真实代价主要是「后续窗口用户质量前移」。

五、策略建议

A

资源聚焦第一周（券有效期），做足触达。

第一周是量质双优窗口：券期内实验组提单率 +7.46pp、盈利率 19.18%、逾期率最低（16.43%）。把召回触达、再营销、客服跟进全部压在第一周内完成。

B

对第二周及以后回归用户升级风控。

第二周实验组逾期率_订单 35.59%、盈利率仅 7.48%；建议对召回日+7 天后首次提单的用户（尤其实验组）加审、压降额度或减少补贴。

C

降息券效果已被到期口径证实为正，重点转向「精准投放」。

到期口径下实验组盈利率反超对照组（17.97% vs 17.63%），30% 降息通过压降坏账实现净收益；优化方向不再是「降档位」，而是「只对第一阶段活跃用户投放、对沉默用户不发券」，规避第二周起回归用户的坏账风险。

附录：完整 PGSQL（到期订单口径）

以下代码覆盖本报告的用户构建、汇总、分组、四周窗口与交叉统计，全部为到期订单 + 分期级口径。执行前请按实际需要调整统计截止日。

模块一：构建 7 月召回实验用户
-- ============================================================
-- 数据源：no_apply_0716_0721_30pct / 0717_0722 / 0718_0723 / 0719_0724
-- 召回日 = 表名最后一个日期（如 0716_0721 -> 2026-07-21）
-- ============================================================
WITH t7 AS (
    SELECT user_id, ab_group, MIN(recall_date) AS recall_date
    FROM (
        SELECT churn_user_id::bigint AS user_id, ab_group,
               DATE '2026-07-21' AS recall_date
        FROM wangchuanliang.no_apply_0716_0721_30pct
        UNION ALL
        SELECT churn_user_id::bigint, ab_group, DATE '2026-07-22'
        FROM wangchuanliang.no_apply_0717_0722_30pct
        UNION ALL
        SELECT churn_user_id::bigint, ab_group, DATE '2026-07-23'
        FROM wangchuanliang.no_apply_0718_0723_30pct
        UNION ALL
        SELECT churn_user_id::bigint, ab_group, DATE '2026-07-24'
        FROM wangchuanliang.no_apply_0719_0724_30pct
    ) x
    GROUP BY user_id, ab_group
)
SELECT ab_group, COUNT(DISTINCT user_id) AS 用户数
FROM t7
GROUP BY ab_group
ORDER BY ab_group;
模块二：各窗口提单率
-- 窗口提单率 = 窗口内提单用户 / 组内实验用户总数
-- 提单以 order_loan_f_v2_copy.apply_date 判定（不受到期口径影响）
WITH t7 AS (
    SELECT user_id, ab_group, MIN(recall_date) AS recall_date
    FROM (
        SELECT churn_user_id::bigint AS user_id, ab_group, DATE '2026-07-21' AS recall_date
        FROM wangchuanliang.no_apply_0716_0721_30pct
        UNION ALL
        SELECT churn_user_id::bigint, ab_group, DATE '2026-07-22'
        FROM wangchuanliang.no_apply_0717_0722_30pct
        UNION ALL
        SELECT churn_user_id::bigint, ab_group, DATE '2026-07-23'
        FROM wangchuanliang.no_apply_0718_0723_30pct
        UNION ALL
        SELECT churn_user_id::bigint, ab_group, DATE '2026-07-24'
        FROM wangchuanliang.no_apply_0719_0724_30pct
    ) x
    GROUP BY user_id, ab_group
)
SELECT
    t7.ab_group                                                             AS 分组,
    COUNT(DISTINCT t7.user_id)                                              AS 用户数,
    COUNT(DISTINCT CASE WHEN o.apply_date BETWEEN t7.recall_date AND t7.recall_date + 6
                         THEN t7.user_id END)                               AS 第一周提单用户,
    ROUND(COUNT(DISTINCT CASE WHEN o.apply_date BETWEEN t7.recall_date AND t7.recall_date + 6
                         THEN t7.user_id END) * 100.0
          / NULLIF(COUNT(DISTINCT t7.user_id), 0), 2)                       AS 第一周提单率,
    COUNT(DISTINCT CASE WHEN o.apply_date BETWEEN t7.recall_date + 7 AND t7.recall_date + 13
                         THEN t7.user_id END)                               AS 第二周提单用户,
    ROUND(COUNT(DISTINCT CASE WHEN o.apply_date BETWEEN t7.recall_date + 7 AND t7.recall_date + 13
                         THEN t7.user_id END) * 100.0
          / NULLIF(COUNT(DISTINCT t7.user_id), 0), 2)                       AS 第二周提单率,
    COUNT(DISTINCT CASE WHEN o.apply_date BETWEEN t7.recall_date + 14 AND t7.recall_date + 20
                         THEN t7.user_id END)                               AS 第三周提单用户,
    ROUND(COUNT(DISTINCT CASE WHEN o.apply_date BETWEEN t7.recall_date + 14 AND t7.recall_date + 20
                         THEN t7.user_id END) * 100.0
          / NULLIF(COUNT(DISTINCT t7.user_id), 0), 2)                       AS 第三周提单率,
    COUNT(DISTINCT CASE WHEN o.apply_date >= t7.recall_date + 21
                         THEN t7.user_id END)                               AS 21天后提单用户,
    ROUND(COUNT(DISTINCT CASE WHEN o.apply_date >= t7.recall_date + 21
                         THEN t7.user_id END) * 100.0
          / NULLIF(COUNT(DISTINCT t7.user_id), 0), 2)                       AS 21天后提单率,
    -- 汇总（累计）提单率
    COUNT(DISTINCT CASE WHEN o.serial_id IS NOT NULL THEN t7.user_id END)   AS 累计提单用户,
    ROUND(COUNT(DISTINCT CASE WHEN o.serial_id IS NOT NULL THEN t7.user_id END) * 100.0
          / NULLIF(COUNT(DISTINCT t7.user_id), 0), 2)                       AS 累计提单率
FROM t7
LEFT JOIN wangchuanliang.order_loan_f_v2_copy o
       ON o.user_id = t7.user_id
      AND o.apply_date >= t7.recall_date
GROUP BY t7.ab_group
ORDER BY t7.ab_group;
模块三：汇总统计
-- 口径：
--   只统计已到期订单：due_date < current_date（未到期订单不统计）
--   分期级：repayment_plan_v2_copy 每期一行，仅计 loan_status_code_period in (7,8)（排除在途5）
--   盈利率 = (sum(repaid_amt_period) - sum(remit_amt_period)) / sum(remit_amt_period)
--   逾期率_金额 = sum(status=8 的 remit_amt_period) / sum(remit_amt_period)
--   逾期率_分期 = count(status=8 分期行) / count(分期行)
--   逾期率_订单 = count(distinct status=8 serial_id) / count(distinct serial_id)
WITH t7 AS (
    SELECT user_id, ab_group, MIN(recall_date) AS recall_date
    FROM (
        SELECT churn_user_id::bigint AS user_id, ab_group, DATE '2026-07-21' AS recall_date
        FROM wangchuanliang.no_apply_0716_0721_30pct
        UNION ALL
        SELECT churn_user_id::bigint, ab_group, DATE '2026-07-22'
        FROM wangchuanliang.no_apply_0717_0722_30pct
        UNION ALL
        SELECT churn_user_id::bigint, ab_group, DATE '2026-07-23'
        FROM wangchuanliang.no_apply_0718_0723_30pct
        UNION ALL
        SELECT churn_user_id::bigint, ab_group, DATE '2026-07-24'
        FROM wangchuanliang.no_apply_0719_0724_30pct
    ) x
    GROUP BY user_id, ab_group
)
SELECT
    t7.ab_group                                                             AS 分组,
    COUNT(DISTINCT a.serial_id)                                             AS 到期件数,
    COUNT(DISTINCT a.user_id)                                               AS 到期人数,
    ROUND(ROUND(SUM(a.repaid_amt_period) - SUM(a.remit_amt_period), 2)
          / NULLIF(ROUND(SUM(a.remit_amt_period), 2), 0) * 100, 2)          AS 盈利率,
    ROUND((SUM(CASE WHEN a.loan_status_code_period = 8 THEN a.remit_amt_period ELSE 0 END) + 0.0)
          / NULLIF(SUM(a.remit_amt_period), 0) * 100, 2)                    AS 逾期率_金额,
    ROUND((COUNT(CASE WHEN a.loan_status_code_period = 8 THEN a.serial_id END) + 0.0)
          / NULLIF(COUNT(a.serial_id), 0) * 100, 2)                         AS 逾期率_分期,
    ROUND((COUNT(DISTINCT CASE WHEN a.loan_status_code_period = 8 THEN a.serial_id END) + 0.0)
          / NULLIF(COUNT(DISTINCT a.serial_id), 0) * 100, 2)                AS 逾期率_订单
FROM t7
JOIN wangchuanliang.repayment_plan_v2_copy a
  ON a.user_id = t7.user_id
 AND a.remit_date >= t7.recall_date
WHERE a.is_remit = 1
  AND a.due_date < current_date
  AND a.loan_status_code_period IN (7, 8)
GROUP BY t7.ab_group
ORDER BY t7.ab_group;
模块四：AB 组 × 四周窗口交叉
-- 第一周=召回日~+6（券期）；第二周=+7~+13；第三周=+14~+20；21天后=+21 起
WITH t7 AS (
    SELECT user_id, ab_group, MIN(recall_date) AS recall_date
    FROM (
        SELECT churn_user_id::bigint AS user_id, ab_group, DATE '2026-07-21' AS recall_date
        FROM wangchuanliang.no_apply_0716_0721_30pct
        UNION ALL
        SELECT churn_user_id::bigint, ab_group, DATE '2026-07-22'
        FROM wangchuanliang.no_apply_0717_0722_30pct
        UNION ALL
        SELECT churn_user_id::bigint, ab_group, DATE '2026-07-23'
        FROM wangchuanliang.no_apply_0718_0723_30pct
        UNION ALL
        SELECT churn_user_id::bigint, ab_group, DATE '2026-07-24'
        FROM wangchuanliang.no_apply_0719_0724_30pct
    ) x
    GROUP BY user_id, ab_group
),
ords AS (
    SELECT t7.ab_group,
           CASE WHEN a.apply_date BETWEEN t7.recall_date AND t7.recall_date + 6
                THEN '第一周'
                WHEN a.apply_date BETWEEN t7.recall_date + 7 AND t7.recall_date + 13
                THEN '第二周'
                WHEN a.apply_date BETWEEN t7.recall_date + 14 AND t7.recall_date + 20
                THEN '第三周'
                ELSE '21天后' END                                             AS win,
           a.serial_id, a.user_id, a.loan_status_code_period,
           a.remit_amt_period, a.repaid_amt_period
    FROM t7
    JOIN wangchuanliang.repayment_plan_v2_copy a
      ON a.user_id = t7.user_id
     AND a.remit_date >= t7.recall_date
    WHERE a.is_remit = 1
      AND a.due_date < current_date
      AND a.loan_status_code_period IN (7, 8)
)
SELECT
    ab_group                                                                AS 分组,
    win                                                                     AS 窗口,
    COUNT(DISTINCT serial_id)                                               AS 到期件数,
    COUNT(DISTINCT user_id)                                                 AS 到期人数,
    ROUND(ROUND(SUM(repaid_amt_period) - SUM(remit_amt_period), 2)
          / NULLIF(ROUND(SUM(remit_amt_period), 2), 0) * 100, 2)            AS 盈利率,
    ROUND((SUM(CASE WHEN loan_status_code_period = 8 THEN remit_amt_period ELSE 0 END) + 0.0)
          / NULLIF(SUM(remit_amt_period), 0) * 100, 2)                      AS 逾期率_金额,
    ROUND((COUNT(CASE WHEN loan_status_code_period = 8 THEN serial_id END) + 0.0)
          / NULLIF(COUNT(serial_id), 0) * 100, 2)                           AS 逾期率_分期,
    ROUND((COUNT(DISTINCT CASE WHEN loan_status_code_period = 8 THEN serial_id END) + 0.0)
          / NULLIF(COUNT(DISTINCT serial_id), 0) * 100, 2)                  AS 逾期率_订单
FROM ords
GROUP BY ab_group, win
ORDER BY ab_group,
         CASE win WHEN '第一周' THEN 1 WHEN '第二周' THEN 2 WHEN '第三周' THEN 3 ELSE 4 END;

-- 历史特征口径不变
WITH feat AS (
    SELECT churn_user_id::bigint AS user_id, ab_group, DATE '2026-07-21' AS recall_date,
           total_remit_rnb, high_interest_rate, overdue_cnt
    FROM wangchuanliang.no_apply_0716_0721_30pct
    UNION ALL
    SELECT churn_user_id::bigint, ab_group, DATE '2026-07-22', total_remit_rnb, high_interest_rate, overdue_cnt
    FROM wangchuanliang.no_apply_0717_0722_30pct
    UNION ALL
    SELECT churn_user_id::bigint, ab_group, DATE '2026-07-23', total_remit_rnb, high_interest_rate, overdue_cnt
    FROM wangchuanliang.no_apply_0718_0723_30pct
    UNION ALL
    SELECT churn_user_id::bigint, ab_group, DATE '2026-07-24', total_remit_rnb, high_interest_rate, overdue_cnt
    FROM wangchuanliang.no_apply_0719_0724_30pct
),
first_apply AS (
    SELECT f.user_id, f.ab_group, f.recall_date, MIN(o.apply_date) AS first_apply_date
    FROM feat f
    JOIN wangchuanliang.order_loan_f_v2_copy o
      ON o.user_id = f.user_id AND o.apply_date >= f.recall_date
    GROUP BY f.user_id, f.ab_group, f.recall_date
),
seg AS (
    SELECT user_id, ab_group, recall_date,
           CASE WHEN first_apply_date BETWEEN recall_date AND recall_date + 6 THEN 'W1'
                WHEN first_apply_date BETWEEN recall_date + 7 AND recall_date + 13 THEN 'W2'
                WHEN first_apply_date BETWEEN recall_date + 14 AND recall_date + 20 THEN 'W3'
                ELSE 'W4' END AS first_win
    FROM first_apply
)
SELECT
    s.first_win                                                             AS 首次提单窗口,
    f.ab_group                                                              AS 分组,
    COUNT(*)                                                                AS 人数,
    ROUND(AVG(f.high_interest_rate)::numeric, 3)                            AS 历史高息率,
    ROUND(AVG(f.overdue_cnt)::numeric, 2)                                   AS 历史逾期订单数,
    ROUND(AVG(f.total_remit_rnb)::numeric, 2)                               AS 历史借款次数
FROM seg s
JOIN feat f ON f.user_id = s.user_id AND f.ab_group = s.ab_group AND f.recall_date = s.recall_date
GROUP BY s.first_win, f.ab_group
ORDER BY s.first_win, f.ab_group;
口径说明（本版为到期订单口径）：召回日 = 各表名最后一个日期（07-21 / 07-22 / 07-23 / 07-24）；第一周 = 召回日至召回日+6（券有效期 7 天，仅实验组享 30% 降息券），第二周 = +7~+13，第三周 = +14~+20，21 天后 = +21 及之后。
只统计已到期订单（due_date < current_date，未到期订单不统计）；分期级统计（repayment_plan_v2_copy 每期一行，仅计 loan_status_code_period ∈ (7,8)，排除在途 status=5）。
盈利率 = (Σrepaid_amt_period − Σremit_amt_period) / Σremit_amt_period；逾期率_金额/分期/订单 三个口径。第三周、21天后到期样本小（<32 件），数值仅供参考。
