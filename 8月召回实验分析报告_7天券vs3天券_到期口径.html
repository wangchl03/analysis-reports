核心结论

02

「决策速度」决定质量：后4天提单的慢决策用户是高质量用户。

无论对照组还是实验组，后4天提单订单的盈利率都高于前3天：对照组后4天 37.27%（前3天 19.35%）、实验组后4天 16.21%（前3天 -6.71%）。历史特征也印证——对照组后4天用户历史高息率 0.219、历史逾期 0.13（全场最低），是最优质的一批。即「可借可不借、慢慢比较后才下单」的用户，财务更健康、还款能力更强。

03

7 天券的问题在前3天「快决策用户」，而非后4天「慢决策用户」。

7 天券前3天拉来的快决策用户逾期率高达 34.35%（对照组前3天仅 15.97%），是整体质量差的根源；而后4天承接的慢决策用户质量反而更好（18.39%），只是仍不如对照组后4天的纯自然回流用户（9.81%）。

六、核心结论汇总

A

7 天券「量增」：累计提单率 +2.64pp。

实验组 53.31% vs 对照组 50.67%，增量全部来自第一周（+2.87pp，7 天券多覆盖 D4~D7）。

B

7 天券「利减」：盈利率 -19.79pp。

实验组 5.53% vs 对照组 25.32%，逾期率更高（30.92% vs 24.89%）。

C

核心机制：决策速度决定质量。

「慢决策」（后4天提单）用户是高质量用户（盈利率高、逾期率低），「快决策」（前3天提单）用户质量更差。7 天券前3天拉来的快决策用户逾期率 34.35%（对照组 15.97%）、首笔亏损 -1.72%，是整体盈利恶化的根源；而 7 天券后4天承接的慢决策用户质量反而更好（16.21%）。

D

低质量是一次性的，复借和非首周用户质量不差。

后续笔（27.42% vs 26.33%）、刨除首周（24.93% vs 22.24%）两组盈利质量接近甚至实验组略优——7 天券的代价集中在「首笔/首周被券吸引的低质量用户」，而非整体。

七、策略建议

A

7 天券的核心风险在前3天「快决策用户」，需针对性风控。

7 天券前3天拉来的快决策用户逾期率 34.35%、首笔亏损 -1.72%；建议对「前3天内首次提单」的用户加审、压降额度，或缩短券期避免承接过多快决策用户。

B

若看重盈利，3 天券优于 7 天券。

7 天券仅比 3 天券多 +2.64pp 提单，却换来 -19.79pp 盈利率；除非「规模增量」能覆盖「首笔劣质用户」的坏账成本，否则不建议扩量 7 天券。

C

复借用户是 7 天券的「正收益来源」，可重点经营。

后续笔订单实验组盈利率 27.42%、逾期率 17.76%，优于首笔；建议对已转化用户重点经营复借，摊薄首笔劣质成本。

模块一：构建 4 批召回用户 + 汇总（到期订单口径）
WITH t7 AS (
    SELECT churn_user_id::bigint AS user_id, ab_group, DATE '2026-08-04' AS recall_date FROM wangchuanliang.no_apply_0730_0804_30pct
    UNION ALL SELECT churn_user_id::bigint, ab_group, DATE '2026-08-05' FROM wangchuanliang.no_apply_0731_0805_30pct
    UNION ALL SELECT churn_user_id::bigint, ab_group, DATE '2026-08-06' FROM wangchuanliang.no_apply_0801_0806_30pct
    UNION ALL SELECT churn_user_id::bigint, ab_group, DATE '2026-08-07' FROM wangchuanliang.no_apply_0802_0807_30pct
)
SELECT t7.ab_group AS 分组,
       COUNT(DISTINCT a.serial_id) AS 到期件数,
       COUNT(DISTINCT a.user_id) AS 到期人数,
       ROUND(ROUND(SUM(a.repaid_amt_period)-SUM(a.remit_amt_period),2)/NULLIF(ROUND(SUM(a.remit_amt_period),2),0)*100,2) AS 盈利率,
       ROUND((SUM(CASE WHEN a.loan_status_code_period=8 THEN a.remit_amt_period ELSE 0 END)+0.0)/NULLIF(SUM(a.remit_amt_period),0)*100,2) AS 逾期率_金额,
       ROUND((COUNT(CASE WHEN a.loan_status_code_period=8 THEN a.serial_id END)+0.0)/NULLIF(COUNT(a.serial_id),0)*100,2) AS 逾期率_分期,
       ROUND((COUNT(DISTINCT CASE WHEN a.loan_status_code_period=8 THEN a.serial_id END)+0.0)/NULLIF(COUNT(DISTINCT a.serial_id),0)*100,2) AS 逾期率_订单
FROM t7
JOIN wangchuanliang.repayment_plan_v2_copy a ON a.user_id=t7.user_id AND a.remit_date >= t7.recall_date
WHERE a.is_remit=1 AND a.due_date < current_date AND a.loan_status_code_period IN (7,8)
GROUP BY t7.ab_group ORDER BY t7.ab_group;
模块二：累计提单率 + 各窗口提单率
WITH t7 AS (
    SELECT churn_user_id::bigint AS user_id, ab_group, DATE '2026-08-04' AS recall_date FROM wangchuanliang.no_apply_0730_0804_30pct
    UNION ALL SELECT churn_user_id::bigint, ab_group, DATE '2026-08-05' FROM wangchuanliang.no_apply_0731_0805_30pct
    UNION ALL SELECT churn_user_id::bigint, ab_group, DATE '2026-08-06' FROM wangchuanliang.no_apply_0801_0806_30pct
    UNION ALL SELECT churn_user_id::bigint, ab_group, DATE '2026-08-07' FROM wangchuanliang.no_apply_0802_0807_30pct
)
SELECT t7.ab_group,
       COUNT(DISTINCT t7.user_id) AS 用户数,
       COUNT(DISTINCT CASE WHEN o.apply_date BETWEEN t7.recall_date AND t7.recall_date+6 THEN t7.user_id END) AS 第一周提单用户,
       ROUND(COUNT(DISTINCT CASE WHEN o.apply_date BETWEEN t7.recall_date AND t7.recall_date+6 THEN t7.user_id END)*100.0/NULLIF(COUNT(DISTINCT t7.user_id),0),2) AS 第一周提单率,
       COUNT(DISTINCT CASE WHEN o.serial_id IS NOT NULL THEN t7.user_id END) AS 累计提单用户,

模块三：AB 组 × 四周窗口交叉（到期口径）
WITH t7 AS (
    SELECT churn_user_id::bigint AS user_id, ab_group, DATE '2026-08-04' AS recall_date FROM wangchuanliang.no_apply_0730_0804_30pct
    UNION ALL SELECT churn_user_id::bigint, ab_group, DATE '2026-08-05' FROM wangchuanliang.no_apply_0731_0805_30pct
    UNION ALL SELECT churn_user_id::bigint, ab_group, DATE '2026-08-06' FROM wangchuanliang.no_apply_0801_0806_30pct
    UNION ALL SELECT churn_user_id::bigint, ab_group, DATE '2026-08-07' FROM wangchuanliang.no_apply_0802_0807_30pct
),
ords AS (
    SELECT t7.ab_group,
           CASE WHEN a.apply_date BETWEEN t7.recall_date AND t7.recall_date+6 THEN '第一周'
                WHEN a.apply_date BETWEEN t7.recall_date+7 AND t7.recall_date+13 THEN '第二周'
                WHEN a.apply_date BETWEEN t7.recall_date+14 AND t7.recall_date+20 THEN '第三周'
                ELSE '21天后' END AS win,
           a.serial_id, a.loan_status_code_period, a.remit_amt_period, a.repaid_amt_period
    FROM t7
    JOIN wangchuanliang.repayment_plan_v2_copy a ON a.user_id=t7.user_id AND a.remit_date >= t7.recall_date
    WHERE a.is_remit=1 AND a.due_date < current_date AND a.loan_status_code_period IN (7,8)
)
SELECT ab_group, win,
       COUNT(DISTINCT serial_id) AS 到期件数,
       ROUND(ROUND(SUM(repaid_amt_period)-SUM(remit_amt_period),2)/NULLIF(ROUND(SUM(remit_amt_period),2),0)*100,2) AS 盈利率,
       ROUND((SUM(CASE WHEN loan_status_code_period=8 THEN remit_amt_period ELSE 0 END)+0.0)/NULLIF(SUM(remit_amt_period),0)*100,2) AS 逾期率_金额,
       ROUND((COUNT(DISTINCT CASE WHEN loan_status_code_period=8 THEN serial_id END)+0.0)/NULLIF(COUNT(DISTINCT serial_id),0)*100,2) AS 逾期率_订单
FROM ords GROUP BY ab_group, win
ORDER BY ab_group, CASE win WHEN '第一周' THEN 1 WHEN '第二周' THEN 2 WHEN '第三周' THEN 3 ELSE 4 END;

WITH t7 AS (

),
w1_users AS (

SELECT t7.ab_group,

    WHERE EXISTS (SELECT 1 FROM wangchuanliang.order_loan_f_v2_copy o WHERE o.user_id=t7.user_id AND o.apply_date BETWEEN t7.recall_date AND t7.recall_date+6)
),
order_seq AS (
    SELECT a.user_id, a.serial_id, MIN(a.remit_time) AS remit_time
    FROM t7 JOIN wangchuanliang.repayment_plan_v2_copy a ON a.user_id=t7.user_id AND a.remit_date >= t7.recall_date
    WHERE a.is_remit=1 GROUP BY a.user_id, a.serial_id
),
marked AS (
    SELECT user_id, serial_id, ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY remit_time, serial_id) AS rn FROM order_seq
)
SELECT t7.ab_group,
       CASE WHEN m.rn=1 THEN '第一笔订单' ELSE '后续笔订单' END AS seg,
       COUNT(DISTINCT a.serial_id) AS 订单数,
       COUNT(DISTINCT a.user_id) AS 用户数,
       ROUND(SUM(a.remit_amt_period),0) AS 放款总额,
       ROUND(SUM(a.repaid_amt_period)-SUM(a.remit_amt_period),0) AS 总利润额,
       ROUND(ROUND(SUM(a.repaid_amt_period)-SUM(a.remit_amt_period),2)/NULLIF(ROUND(SUM(a.remit_amt_period),2),0)*100,2) AS 盈利率,
       ROUND((SUM(CASE WHEN a.loan_status_code_period=8 THEN a.remit_amt_period ELSE 0 END)+0.0)/NULLIF(SUM(a.remit_amt_period),0)*100,2) AS 逾期率_金额
FROM t7
JOIN w1_users w ON w.user_id=t7.user_id AND w.ab_group=t7.ab_group
JOIN marked m ON m.user_id=t7.user_id
JOIN wangchuanliang.repayment_plan_v2_copy a ON a.user_id=t7.user_id AND a.serial_id=m.serial_id AND a.remit_date >= t7.recall_date
WHERE a.is_remit=1 AND a.due_date < current_date AND a.loan_status_code_period IN (7,8)
GROUP BY t7.ab_group, seg ORDER BY t7.ab_group, seg;

WITH t7 AS (
    SELECT user_id, ab_group, MIN(recall_date) AS recall_date FROM (
        SELECT churn_user_id::bigint AS user_id, ab_group, DATE '2026-08-04' AS recall_date FROM wangchuanliang.no_apply_0730_0804_30pct
        UNION ALL SELECT churn_user_id::bigint, ab_group, DATE '2026-08-05' FROM wangchuanliang.no_apply_0731_0805_30pct
        UNION ALL SELECT churn_user_id::bigint, ab_group, DATE '2026-08-06' FROM wangchuanliang.no_apply_0801_0806_30pct
        UNION ALL SELECT churn_user_id::bigint, ab_group, DATE '2026-08-07' FROM wangchuanliang.no_apply_0802_0807_30pct
    ) x GROUP BY user_id, ab_group
),
w1_users AS (
    SELECT t7.user_id, t7.ab_group FROM t7
    WHERE EXISTS (SELECT 1 FROM wangchuanliang.order_loan_f_v2_copy o WHERE o.user_id=t7.user_id AND o.apply_date BETWEEN t7.recall_date AND t7.recall_date+6)
)
SELECT t7.ab_group,
       COUNT(DISTINCT a.serial_id) AS 到期件数,
       COUNT(DISTINCT a.user_id) AS 到期人数,
       ROUND(SUM(a.remit_amt_period),0) AS 放款总额,
       ROUND(SUM(a.repaid_amt_period)-SUM(a.remit_amt_period),0) AS 总利润额,
       ROUND(ROUND(SUM(a.repaid_amt_period)-SUM(a.remit_amt_period),2)/NULLIF(ROUND(SUM(a.remit_amt_period),2),0)*100,2) AS 盈利率,
       ROUND((SUM(CASE WHEN a.loan_status_code_period=8 THEN a.remit_amt_period ELSE 0 END)+0.0)/NULLIF(SUM(a.remit_amt_period),0)*100,2) AS 逾期率_金额,
       ROUND((COUNT(DISTINCT CASE WHEN a.loan_status_code_period=8 THEN a.serial_id END)+0.0)/NULLIF(COUNT(DISTINCT a.serial_id),0)*100,2) AS 逾期率_订单
FROM t7
LEFT JOIN w1_users w ON w.user_id=t7.user_id AND w.ab_group=t7.ab_group
JOIN wangchuanliang.repayment_plan_v2_copy a ON a.user_id=t7.user_id AND a.remit_date >= t7.recall_date
WHERE w.user_id IS NULL AND a.is_remit=1 AND a.due_date < current_date AND a.loan_status_code_period IN (7,8)
GROUP BY t7.ab_group ORDER BY t7.ab_group;
口径说明：4 批 T4 用户合并（召回日 08-04/05/06/07），实验组 7 天 30% 降息券、对照组 3 天 30% 降息券。累计提单率 = 召回后累计提单；盈利率/逾期率为到期订单口径（due_date < current_date，分期级 repayment_plan_v2_copy，仅计 loan_status_code_period ∈ (7,8)）。盈利率 = (Σrepaid_amt_period − Σremit_amt_period) / Σremit_amt_period。
